# LLM API Server

An Anthropic-format LLM proxy: every request is classified (task, domain, complexity, risk), routed to the cheapest model that can do the job, converted to the provider's native format, and accounted down to the token. Ships with a Next.js dashboard for cost, tokens, and routing.

```
Client (Claude Code, API)
        │  POST /v1/messages (Anthropic format)
        ▼
┌───────────────────────────────┐
│  classifier  ──▶  router  ──▶  provider (deepseek / anthropic / openai / gemini)
│  (hybrid, cached)   (cost/quality modes + policy)
└───────────────────────────────┘
        │  response converted back to Anthropic format
        ▼
   metrics (session + persistent global) ──▶ GET /metrics ──▶ dashboard (Next.js, :3000)
```

## Quick start

Requirements: Node 22+, API keys in `.env` (gitignored):

```
CLAUDE_API_KEY=sk-ant-...      # or ANTHROPIC_API_KEY
DEEPSEEK_API_KEY=sk-...
# optional: OPENAI_API_KEY, GOOGLE_API_KEY or GEMINI_API_KEY
```

```bash
# server (port 8002, or PORT=...)
npm start

# dashboard (separate terminal, port 3000)
cd dashboard
pnpm install
pnpm dev
```

Open http://localhost:3000. Hit "Generate demo traffic" on the Overview page to populate every panel without calling a provider (runs the real classifier + router, simulates provider results).

## API

| Endpoint | Purpose |
|---|---|
| `POST /v1/messages` | Main proxy. Anthropic-format body; `stream: true` supported. Routes via the classifier + router (see Routing mode below). `?debug=1` adds `_classification`/`_compaction` to the response; classification also rides the `X-Classification` header |
| `POST /v1/classify` | Classification only, no provider call |
| `GET /health` | Server status, available models |
| `GET /metrics` | Full metrics snapshot (session + persisted global) |
| `POST /metrics/demo` | 12-prompt burst through the real classifier + router (session-only, never in the persisted counter) |
| `POST /metrics/eval` | Run the labeled eval set (config/eval-prompts.json) |
| `POST /metrics/reset` | Reset session; `?global=1` also wipes the all-time counter |
| `GET /config/dashboard` | Model catalog (with enabled state), routing prefs, router policy, benchmark report |
| `POST /config/models` | `{id, enabled}` - toggle a model in/out of auto-routing |
| `POST /config/routing` | `{mode}` - set the default routing mode |

**Routing mode:** `X-Routing-Mode: cheap | fast | balanced | quality` per request; otherwise the dashboard-configured default (`data/dashboard-prefs.json`), then `cheap`. Note: when `classifier.mode` is `"auto"` in config/server.json, named models are ignored and every request is classified + routed (this is the cost-saving default).

## Configuration

| File | What it controls |
|---|---|
| `config/models.json` | Model registry: provider, apiModelId, capabilities, cost tiers, task profiles |
| `config/pricing.json` | **Single source of truth for cost math** (per-model rates, cache multipliers, cost-savings baselines) |
| `config/server.json` | Classifier mode/cache, router weights, fallback chain, cache breakpoint injection, compaction policy |
| `config/router-policy.json` | Data-driven cost-tier floors per task/complexity (generated by `benchmark/fit-policy.js`) |
| `config/eval-prompts.json` | Labeled eval set for the classifier |
| `data/dashboard-prefs.json` | Runtime prefs: default routing mode + disabled models (gitignored, survives restarts) |
| `data/usage-stats.json` | Persisted all-time counters (gitignored) |

## Cost accounting

- Every request records tokens and cost at 6-decimal USD precision: provider spend (cache-aware), classifier LLM calls, and compaction summaries.
- **Fair baselines:** "cost saved" compares your actual spend against the *same token bundle* (plain in/out + cache reads/writes) priced on a fixed model (DeepSeek V4 Pro / Claude Opus 4.8) at that model's own cache rates.
- **Cache pricing:** Anthropic reads 0.1x, writes 2x (because the injected breakpoints use the 1-hour TTL; the 5-minute TTL would be 1.25x writes). DeepSeek hits ~2-3.3% of input.

## Request sanitization (why it exists)

The router swaps models per request, but the client replays history produced by whichever model served earlier turns. The proxy normalizes per target model:

- `max_tokens` is clamped to the selected model's output cap (a client value above the cap is a hard 400).
- `thinking`/`redacted_thinking` blocks are stripped (signatures are bound to the producing model).
- Mid-conversation `role: "system"` messages are demoted to `user` on models that don't support them (only opus-4-8+/fable/mythos do).
- Per-message `output_config` is stripped on models that don't support it.

Each transform logs a `✂️` line. Provider 400s log the real upstream error body.

## Debugging

- `system.txt` receives the complete incoming body of every `/v1/messages` request. It is **gitignored** because it contains raw request payloads - never force-add it to git, and truncate it occasionally (it grows without bound).
- `POST /metrics/demo` + the dashboard is the fastest way to eyeball routing behavior.

## Security

This server has **no authentication** - it is meant to run on localhost or a trusted network. Anyone who can reach the port can proxy prompts through your API keys, read metrics, and change routing settings. Do not expose port 8002 (or the dashboard) to the public internet. API keys live only in the gitignored `.env`.
